# Corgi-Bot Website V1.3 — V6.2 Dashboard Sync

- Uses V1.2 FINAL as the base; existing public website/community pages are preserved.
- Replaces retired `/guild` directory entry with `/clan`.
- Rebuilds Server Dashboard into a tabbed control center.
- Server setup: 12 languages, module toggles, channel routing, Verified/Partner badge availability.
- Giveaway and Contest builders with image file uploads.
- Clan: create/edit identity, privacy, member cap, custom currency, join requirements, member invites, treasury visibility, logo/banner uploads and rank permission editing.
- Clan Members: ranks and trust/contribution/currency adjustments.
- Applications: approve/decline.
- Shop: virtual/physical items, stock, description, delivery note and up to six uploaded images.
- Orders: approve/fulfill/decline/refund with handler notes.
- Missions: cadence, metric, target, rewards and schedule.
- Events: schedule, rewards and status display.
- Audit log and dashboard overview.
- Adds VITE_CORGI_API_URL and VITE_SUPABASE_ASSET_BUCKET to .env.example.

## Safety / API scope
The website only exposes operations already supported by the V6.2 Web API. Verification approval/review/revoke is intentionally left in the bot Developer Control Panel because the supplied Web API does not expose a protected verification-review endpoint.

## Build note
A production build could not be executed in the artifact environment because dependencies are not bundled and dependency installation exceeded the execution window. Run `npm install && npm run build` in the normal deployment environment before publishing.
